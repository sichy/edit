## Thread

**1/5**
Remember Borland C++ and its draggable windows? I rebuilt that in my Rust fork of Microsoft Edit, the terminal text editor. 🧵

**2/5**
Every panel is now a Turbo Vision style window: double-line frame when active, [■] close, [↑] zoom.

Drag a title bar onto a screen edge to dock, next to a window to split, onto one to swap. A live outline shows where it will land.

**3/5**
Drag the lines between docked windows to resize. Float any window above the layout and resize it from its corner.

The keys are the classic ones: F6 cycles, F5 zooms, Ctrl+F5 moves and sizes with the arrows. The layout is saved between sessions.

**4/5**
There's also a new AI Assistant window: a chat with message history, a multi-line prompt and a New chat button, dockable like everything else.

The UI is done; wiring up a model is next.

**5/5**
Syntax highlighting now runs on the upstream LSH engine, which covers about 30 languages, with my own dark theme on top.

Code: https://github.com/sichy/edit
Built on @Microsoft's Edit: https://github.com/microsoft/edit
