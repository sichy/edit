## Intent

Launch teaser for "Edit", a fork of Microsoft Edit for the terminal with a full
visual redesign, docking windows and a built-in AI Assistant. Modern motion
design: real editor screens tilted into an isometric stack, camera glides and
zooms into each window as it docks. Opens on a 1991-style blue MS-DOS Edit
screen with CRT glow that glitches and rebuilds into the modern editor.

## Assets

- Fresh editor screens captured with the pty+pyte harness (a temporary script, not kept),
  rendered at 2x for crisp zooms. No user-supplied material.

## Customizations

- Music bed with cuts on the beat, plus UI sound effects.
- Isometric zooms into real screens.
- 1991 → 2026 opening: blue DOS Edit with CRT glow, glitch, rebuild.

## Notes

- Time budget: about 4s DOS hook, about 20s for three features (docking windows,
  AI Assistant composer, new look), about 6s launch end card.
- File browser, search and menus appear only as background shots.
- Palette from the editor theme: charcoal surfaces, one blue accent, monospace.
- On-screen copy: "Windows that dock", "An assistant built in", "A new look";
  end card "Edit" / "Now in your terminal". No em-dashes, no URL.
